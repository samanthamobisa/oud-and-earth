# Oud & Earth — Luxury Fragrance Store

A fully responsive multi-page web application for a luxury perfume and cologne brand, **Oud & Earth**. Built as part of a Web Application Development course project using HTML5, CSS3, JavaScript (ES6+), and Bootstrap 5.

---

## Live Preview

> Coming soon — will be deployed via GitHub Pages

## Project Overview

**Oud & Earth** is a premium fragrance e-commerce showcase inspired by the rich, earthy scent traditions of the Middle East and Africa. The site presents a curated collection of perfumes and colognes, brand storytelling, a fragrance blog, and a fully functional contact experience.

---

##  Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero banner, featured scents, brand highlights |
| Shop | `shop.html` | Full product grid with gender/scent filter |
| Product Detail | `product.html` | Individual fragrance page with notes & description |
| About | `about.html` | Brand story, values, how our scents are crafted |
| Blog | `blog.html` | Articles on fragrance tips, trends, and culture |
| Gallery | `gallery.html` | Visual showcase of bottles, ingredients & lifestyle |
| FAQ | `faq.html` | Shipping, returns, and fragrance guidance |
| Contact | `contact.html` | Contact form with JavaScript validation |

---

##  Technologies Used

- **HTML5** — Semantic structure across all pages
- **CSS3** — Custom styles, animations, media queries
- **JavaScript (ES6+)** — Interactivity and form validation
- **Bootstrap 5** — Responsive grid, navbar, modals, components

---

##  JavaScript Features

1. **Product Filter** — Filter fragrances by category (Men / Women / Unisex / All) on the Shop page
2. **Dark / Light Mode Toggle** — Switch between dark and light themes across all pages
3. **Contact Form Validation** — Real-time validation with error messages on the Contact page

| Element | Value |
